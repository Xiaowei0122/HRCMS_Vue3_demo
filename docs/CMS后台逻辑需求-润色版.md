## 一、工程师接单与管理员指派（两端联动）

### 需求描述

1. **工程师端（小程序 + 后台）**：工单列表不显示「指派」按钮，而是显示「**接单**」按钮。工程师点击接单后，弹出预约弹窗，选择**预约日期**和**预约时段**。若该时段已被其他工单占用，下拉框中对应时段应**灰色不可选**。工程师确认预约后，工单状态更新。

2. **管理员端**：管理员拥有「**指派**」权限，可主动将工单指派给任意工程师（含日期+时段）。指派后同步更新排期表。

3. **业务端（内部人员）**：提单人员可对工单发起「**确认预约**」操作，提交期望的预约时间；但最终预约时间由工程师接单时确定。

4. **角色权限总结**：
   - **管理员（admin）**：可指派（任意工程师）+ 所有操作权限
   - **工程师（engineer）**：可接单（仅绑定自己）
   - **业务/内部人员（business 等）**：可确认预约（发起预约请求）
   - **普通用户**：仅可报修、查看自己的工单

5. **排期联动**：所有指派 / 接单 / 确认预约操作，确认后均须与工程师排期表实时联动，避免时段冲突。

### 实现状态：✅ 已完成

| 功能点 | 后端 | 前端 | 状态 |
|--------|------|------|------|
| 管理员指派 | `PATCH /repairs/{id}/assign`（rank≤1） | `AllTasks.vue` 指派弹窗 | ✅ |
| 工程师接单 | `PATCH /repairs/{id}/accept`（仅 engineer） | `AllTasks.vue` 接单弹窗 | ✅ |
| 业务确认预约 | `POST /repairs/{id}/reserve` | `AllTasks.vue` 确认预约按钮 | ✅ |
| 时段冲突检测 | `_slot_occupied()` 后端校验 | 前端 `getScheduleAvailability` 灰显已占用时段 | ✅ |
| 排期联动 | 接单/指派后自动写入 `repair_schedule` | `EngineerSchedule.vue` 周视图矩阵 | ✅ |

## 四、工程师转单机制

### 需求描述

当工程师无法处理当前工单时，可发起**转单申请**，将工单转给其他工程师。转单需保留完整流转节点，支持以下生命周期：

1. **发起转单**：当前处理工程师选择目标工程师，提交转单申请。
2. **接受转单**：目标工程师接受后，工单处理人更新，排期表同步更新。
3. **拒绝转单**：目标工程师可拒绝，工单回到原处理人。
4. **取消转单**：发起工程师可在被处理前取消转单申请。

**核算规则**：导出工单核算工单数量和成本时，按**最终处理人**计算。

### 实现状态：⚠️ 部分完成（后端完整；小程序端已有，后台 Web 端缺失）

| 端点 | 后端 | Web 后台 |
|------|------|------|
| `PATCH /repairs/{id}/transfer`（发起转单） | ✅ | ❌ 无按钮 |
| `POST /repairs/{id}/transfer/accept`（接受） | ✅ | ❌ 无按钮 |
| `POST /repairs/{id}/transfer/reject`（拒绝） | ✅ | ❌ 无按钮 |
| `POST /repairs/{id}/transfer/cancel`（取消） | ✅ | ❌ 无按钮 |

### 已发现 Bug

| # | 严重度 | 描述 | 位置 |
|---|--------|------|------|
| B7 | 🔴 高 | **后台 Web 端转单 UI 缺失**：后端 4 个转单端点全部就绪，小程序端（`miniprogram/src/pages/repair-detail/index.vue`）也已有转单按钮；但后台 `AllTasks.vue` 操作列（第 118-120 行）没有「转单」按钮，`RepairDetail.vue` 仅展示转单信息（只读），无操作入口。管理员/工程师无法在 **Web 后台** 发起或处理转单 | `AllTasks.vue`、`RepairDetail.vue` |

## 七、系统时间修复（服务器时间统一）

### 需求描述

系统应统一使用**服务器时间**（北京时间 UTC+8），而非客户端时间。涉及以下场景：

- 工单创建时间、更新时间
- 排期过期判断
- 日期选择器的「禁用过去日期」判断
- 导出文件名中的日期
- 报单时间与服务器时间对应

### 实现状态：⚠️ 部分完成

| 场景 | 状态 | 说明 |
|------|------|------|
| 后端时间戳 | ✅ | `timeutil.py` 统一使用 `now_cn()`（UTC+8） |
| 服务器时间接口 | ✅ | `GET /public/server-time` 返回 `datetime` / `date` / `timestamp` |
| 前端接单日期初始化 | ✅ | `AllTasks.vue` 调用 `getServerTime()` 初始化 `serverDate` |
| 排期过期判断 | ❌ | `taskStore.js` `getCellStatus()` 使用客户端 `dayjs()` |
| 日期禁用判断 | ❌ | `disablePastDate` 使用客户端 `Date.now()` |
| 导出文件名日期 | ❌ | 使用客户端 `new Date().toLocaleDateString()` |
